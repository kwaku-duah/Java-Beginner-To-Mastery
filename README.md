This is a helloworld REST API with java springboot.
This project takes a step by step approach in grasping everything springboot is
with maven from scratch to microservices level .

Take a seat and a walk through Java Springboot for programming
Important concepts to understand from spring framework before jumping fully into
springboot:
    ## Dependency Injection: Literal Explanation: You want a car but you will take
    forever to build yourself one, so you delegate authority to let's Tesla, 
    they build ready car for you. That is dependency injection, you give authority
    to spring to create objects for you.

    ## Inversion of Control: Literal Explanation: You want a set of toys, you are 
    the boss, but you give control to spring, so that it controls creation of the
    toys and connection of the toys, so in this regard, you give up control and give
    it to spring while you sit back

    ## Aspect Oriented Programming: Literal Explanation: You want all the toys to 
    scream hello world, but you have to painfully configure each and everyone of the toys,
    in order to solve this problem, you instead to decide to build a remote that when triggered
    will get all toys to scream hello world all at once
    ## Bean and applicationContext: Literal Explanation: You want a collection of certain toys,
    so you tell spring, spring packages all the toys in a box( that is context) and delivers it 
    to you when you need it. A bean is simply a toy that spring manages, so in essence
    an object that spring manages is called a bean
